Backup dan pemulihan data

Ekspor data untuk menyimpan salinan pelanggan dan riwayat aktivitas. Impor file backup untuk memulihkan data di browser ini. Jangan bagikan file backup karena dapat berisi nomor telepon pelanggan.

Informasi prototipe

Saat ini Nexa CRM berjalan langsung di browser dan menyimpan data di perangkat yang digunakan. Sinkronisasi antar HP dan laptop, login akun, notifikasi otomatis, dan APK Android perlu tahap pengembangan serta server berikutnya. Data bisa hilang jika data browser dihapus, jadi lakukan backup secara berkala.
